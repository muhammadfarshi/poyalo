# Poyalo (പോയാലോ?)

A story-first travel companion progressive web application (PWA).

## Overview

Poyalo connects travelers with local culture, history, and community through place-bound storytelling, interactive exploration, and local guides.

## Features (Planned)

- **Story Box**: Curated place-bound historical tales and cultural narratives.
- **Interactive History Exploration**: Location-aware challenges and local cuisine guides.
- **AI Travel Planner**: Personalized trip itineraries with offline-first capabilities.
- **Local Guides & Curators**: Connect directly with trusted local storytellers and guides.
